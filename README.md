# Rhino Project Framework

This is the repository of gems and packages that make up the Rhino Project Framework, it is for core development not for building new projects.

See https://www.rhino-project.org/docs/getting_started/ for building new projects.

## Installation and build

```bash
pnpm i
pnpm watch
```
